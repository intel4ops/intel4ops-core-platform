# WP-2.21 Signature Readiness

WP-2.20 does not implement proprietary signatures. Scenario contracts preserve ordered
events, observation and feature windows, prediction horizon, target, context,
exclusions, intervention, confirmed outcome, false-positive/negative classification,
validation split, holdout designation, candidate ID, and artifact version. WP-2.21 can
reuse these governed scenarios and oracles without pooling cross-tenant raw data.
