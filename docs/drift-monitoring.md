# Drift Monitoring

Monitoring policies declare baseline and comparison periods, sample minimums,
thresholds, warning/failure/suspension actions, review ownership, and recalibration
policy. Required dimensions include input, feature, prediction, outcome, accuracy,
calibration, rule yield, finding volume, confidence, economic impact, and recovery
success. WP-2.20 detects and governs drift; it never retrains or promotes autonomously.
