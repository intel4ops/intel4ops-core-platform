# Release Waivers

Waivers are exceptional, gate-specific, approved, time-bounded records with
justification and compensating control. Expired, unapproved, or non-waivable gate
waivers are rejected. No API or CLI option overrides a non-waivable failure. The
independent-review exception for repository governance is documented on the pull
request and is separate from technical release-gate waivers.
