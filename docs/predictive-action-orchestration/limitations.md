# Limitations

- Recommendation, priority, and approval policies are bounded deterministic rules, not generative
  decisions or guarantees.
- Only direct two-node dependency cycles are currently detected.
- No live CMMS, inventory, workforce, permit, or work-order connector is implemented.
- Resource confirmation is only as current as its evidence and source reference.
- Model feedback is stored for governed future calibration; models are not retrained automatically.
- Reopening verified actions requires a future explicit governance mechanism.
