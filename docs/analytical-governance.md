# Analytical Governance

Analytical artifacts progress through `draft`, `under_review`, `validated`, `approved`,
`active`, `suspended`, `deprecated`, and `retired`. Only `active` versions may execute
in production mode. Active versions are immutable; changes create a new version.
Governance records reference, rather than duplicate, OIKB definitions, registered
methods, models, thresholds, calibration profiles, and pack rule bindings.
