# Industry Packs

WP-2.19 publishes four version `1.0.0` packs:

- `PACK-J2C` — Job-to-Cash
- `PACK-MFG` — Manufacturing
- `PACK-PORTS` — Ports and Terminals
- `PACK-MOB` — Mobility and Public Transport

Every component declares a universal parent. Each pack includes ontology and
canonical mappings, an exposure metric, six governed deterministic rule bindings,
evidence requirements, currency-safe exposure behavior, and six recovery playbooks.
Use the authoring and validation guides before proposing a new version.
