# Job-to-Cash Pack

`PACK-J2C` version `1.0.0` is entitled by `industry.job_to_cash`. Its rules cover
commercial-not-invoiced, underbilling, margin, documentation, payment, and rework.
The pack binds governed metadata to the existing WP-2.18 Job-to-Cash orchestration;
it does not duplicate that engine, canonical records, findings, or evidence.
