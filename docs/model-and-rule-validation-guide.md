# Model and Rule Validation Guide

Rules require boundary, reproducibility, evidence, trace, false-positive/negative,
idempotency, and currency tests. Statistical methods use precision, recall, stability,
missing-data and drift sensitivity. Forecasts use MAE, RMSE, bias, interval coverage,
and horizon/backtest stability. Reliability uses calibration, concordance, lead time,
censoring, and segmentation. Optimization uses feasibility, constraints, baseline
comparison, runtime, explanation, determinism, and safe fallback. No universal score
replaces these artifact-specific measures.
