# Statistical Intelligence Security

Every persisted operational row is organization scoped, and every execution,
baseline, observation, review and suppression lookup filters by `organization_id`.
Existing membership roles map separately to read, run, method-read, review,
suppression-management and administration permissions. System method administration
remains platform-controlled.

Peer evidence is aggregate-only. Private OIKB resolution permits only the owning
organization. Inputs reject mixed units/currencies and non-finite numbers. No secrets,
raw customer datasets, unrestricted expressions, dynamic imports or cross-tenant raw
benchmarks are stored or executed.
