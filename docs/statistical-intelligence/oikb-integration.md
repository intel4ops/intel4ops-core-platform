# OIKB Integration

Only active, effective statistical OIKB versions may execute. WP-2.11 extends the
existing immutable package exporter to the `statistical` analytical level. The
expression schema declares only a registered method code/version plus bounded
baseline, threshold and false-positive policies; it is never evaluated as code.

Twelve provisional active seeds demonstrate shared, job-to-cash, manufacturing and
mobility use cases. Each has Intel4Ops provenance, approval, input/evidence contracts,
Trust/readiness requirements, limitations, and 21 deterministic validation-contract
cases. Unsupported methods return a structured `UNSUPPORTED` outcome.
