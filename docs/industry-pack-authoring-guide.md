# Industry-Pack Authoring Guide

Create a semantic-versioned manifest with pack identity, minimum platform revision,
Trust policy, and typed components. Component keys are unique by type and code.
Ontology mappings, canonical extensions, metrics, OIKB rule bindings, evidence
requirements, economic mappings, and recovery playbooks must name a universal
parent. Declare units explicitly and use organization-default currency behavior for
money; never combine currencies.

Create a draft through the platform API, validate it, obtain approval, then publish.
Adding a future vertical requires a manifest and optional executor registration—not
changes to shared tenant, finding, economics, or recovery models.
